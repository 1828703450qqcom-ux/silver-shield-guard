# 可选 ONNX 模型接入

本目录目前**没有模型权重文件**。项目包含 ONNX Runtime 依赖与推理封装，但未提供训练数据、模型许可证、标签映射或性能评测；没有依据宣称准确率、召回率、模型体积或推理耗时。没有模型时应使用本地规则回退路径。

如需接入，请先阅读 `OnnxRuntimeManager.kt` 和调用方的输入输出处理，确认模型节点名称、数据类型、形状、预处理及标签顺序全部匹配；添加可再分发的 `.onnx` 文件后，在真实设备上做完整回归测试，并记录模型来源、版本、许可证和独立测试集结果。不要将含个人信息的训练数据或未经授权的模型放进公开仓库。

语音识别当前依赖设备/系统可用服务，并不随仓库提供离线方言模型。
