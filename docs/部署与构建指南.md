# 部署与构建指南

银盾守护目前是单机 Android 原型，部署对象是 APK，没有服务器、域名或数据库迁移步骤。以下步骤以仓库中的 `compileSdk 34`、`minSdk 26`、JDK 17、Gradle 8.2.1 为准。

## 1. 环境准备

1. 安装 Android Studio 和 JDK 17。
2. 在 Android Studio 的 SDK Manager 安装 **Android SDK Platform 34**、Build-Tools 与 Platform-Tools。
3. 克隆仓库并在 Android Studio 中打开仓库根目录，等待 Gradle 同步。首次同步需要网络下载依赖。
4. 确保 Android Studio 的 Gradle JDK 指向 JDK 17。若 SDK 未被自动识别，可在项目根目录创建不提交的 `local.properties`，写入本机 `sdk.dir`。

```powershell
git clone https://github.com/1828703450qqcom-ux/silver-shield-guard.git
cd silver-shield-guard
.\gradlew.bat --version
.\gradlew.bat assembleDebug
```

macOS/Linux 对应命令为 `./gradlew assembleDebug`。仓库包含 Gradle Wrapper，无须单独安装全局 Gradle。成功后 APK 位于 `app/build/outputs/apk/debug/app-debug.apk`。

## 2. 安装与演示

使用 Android 8.0（API 26）及以上的模拟器或测试机。在设备上开启开发者选项和 USB 调试，执行：

```powershell
adb devices
adb install -r app\build\outputs\apk\debug\app-debug.apk
```

也可在 Android Studio 选择设备后点击 Run。首次使用时按系统提示授予演示所需权限。通知、来电识别、后台运行和语音能力在不同 Android 版本及厂商系统上表现不同；请在目标设备上逐项验证。**不要输入真实银行卡、验证码和身份信息**。

建议演示顺序：进入首页 → 浏览反诈训练 → 查看本地来电/交易风险页面 → 编辑举报材料 → 查看家庭守护和设置。账户、交易和奖励内容均为示例或本地状态，不能当作真实金融流水、现金奖励或报案回执。

## 3. 构建检查

```powershell
.\gradlew.bat clean assembleDebug
.\gradlew.bat testDebugUnitTest
```

项目当前没有覆盖全部业务场景的自动化测试。构建成功只说明源码可编译，不证明诈骗识别准确性或系统级拦截能力。需要验证权限、通知、语音和后台行为时，请在真实设备上做手工测试。

## 4. 发布版准备

`assembleRelease` 只能生成未签名或需另行签名的发布构建。正式分发前，在本机安全生成并保管签名密钥，通过本地未跟踪配置或环境变量注入签名信息；不要把 `.jks`、口令或含密钥的 `local.properties` 提交到 GitHub。再检查应用图标、隐私说明、权限用途、无障碍表现、设备兼容性及依赖许可。当前仓库未配置发布流水线或应用商店上架流程。

## 5. 常见问题

| 现象 | 排查方向 |
|---|---|
| 找不到 Android SDK | 在 SDK Manager 安装 Platform 34；检查本机 `local.properties` 的 `sdk.dir`。 |
| Gradle 下载失败 | 确认网络可访问 Gradle 与 Google Maven，重试同步；不要把下载缓存提交进仓库。 |
| Java 版本错误 | 将 Android Studio Gradle JDK 和命令行 `JAVA_HOME` 切到 JDK 17。 |
| 模型未加载 | 仓库不含 ONNX 权重，规则回退路径是预期行为；详见模型说明。 |
| 来电/通知无效果 | 检查系统权限、默认拨号/筛选角色和厂商后台限制；本原型未证明系统级拦截。 |
